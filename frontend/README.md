# Frontend với React

## Cài đặt

```bash
npm install
```

## Chạy development server

```bash
npm start
```

Ứng dụng sẽ mở tại http://localhost:3000

## Build cho production

```bash
npm run build
```

## Cấu trúc

- `src/components/`: React components
- `src/services/`: API services (axios)
- `src/App.js`: Main application component
